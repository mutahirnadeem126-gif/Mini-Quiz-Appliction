# Python Mini Quiz Application

A simple command-line interface (CLI) quiz application built in Python that tests fundamental programming concepts, validates user answers, and calculates the final score.

## Features

- **Structured Question Bank:** Stores questions and answers using a Python list of dictionaries.
- **Case-Insensitive Validation:** Automatically trims extra spaces and ignores capitalization when checking user answers.
- **Instant Feedback:** Displays whether each answer is correct or reveals the right answer immediately.
- **Score Summary:** Tracks and displays total correct answers, wrong answers, and the final score upon completion.

## Concepts Practiced

- Lists and Dictionaries (`list` of `dict`)
- Loops (`for` loop with `enumerate()`)
- Conditional Statements (`if`/`else`)
- Functions and Modular Code
- String Methods (`.strip()`, `.lower()`)
- User Input & Output
